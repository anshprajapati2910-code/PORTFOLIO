## Run Locally

```bash
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
```

Then open `index.html` in your browser. No build step needed.

## Deploy on GitHub Pages

1. Rename `My Project.html` to `index.html` and push it to a GitHub repo.
2. Go to **Settings → Pages**.
3. Set **Source** to *Deploy from a branch*, choose **main** and **/ (root)**, then click **Save**.
4. Your site goes live at `https://<your-username>.github.io/<your-repo-name>/`.
